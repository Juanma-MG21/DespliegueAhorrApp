# RF-15 · Gestionar categorías financieras

Verificar que el titular pueda gestionar categorías personalizadas y que las categorías globales o del sistema estén protegidas.

- [React](rf15.test.jsx) comprueba las consultas por módulo, los controles de categorías globales, el rechazo de duplicados y el ciclo de alta, edición, deshabilitación, reactivación y eliminación con confirmación.
- [API](rf15.api.test.cjs) comprueba autenticación, nombre obligatorio, filtros de propiedad y protección, y rechazo de eliminación de una categoría activa.

```powershell
npm test --prefix Frontend -- rf15
npm test --prefix Backend -- rf15
```

Queda por verificar en PostgreSQL que deshabilitar conserve las asociaciones y que eliminar deje los movimientos sin categoría.
