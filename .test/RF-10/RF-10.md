# RF-10 · Gestionar dependientes económicos

Verificar que el titular pueda consultar, registrar, editar y eliminar dependientes y que la API rechace accesos y datos inválidos.

- [React](rf10.test.jsx) comprueba consulta, alta con datos normalizados, edición y cancelación o confirmación de eliminación.
- [API](rf10.api.test.cjs) comprueba JWT, nombre y relación obligatorios, fecha válida, peso entero de 1 a 5, titularidad, acceso administrativo y consulta agrupada de gastos por dependiente.

```powershell
npm test --prefix Frontend -- rf10
npm test --prefix Backend -- rf10
```

Queda por verificar la persistencia en PostgreSQL y la asociación de un gasto con un dependiente desde el formulario.
