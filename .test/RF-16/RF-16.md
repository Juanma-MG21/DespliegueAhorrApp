# RF-16 · Cerrar sesión

Verificar que cerrar sesión retire las credenciales locales y proteja el acceso posterior.

- [React](rf16.test.jsx) comprueba limpieza de ambos almacenamientos, conservación de preferencias, redirección desde una ruta protegida y revalidación ante cambios de almacenamiento y al volver desde el historial.

```powershell
npm test --prefix Frontend -- rf16
```

La revocación del token en el servidor queda fuera del contrato del RF. La redirección se comprueba en un entorno simulado y se puede verificar manualmente en el navegador.
